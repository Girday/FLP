## Описание лабораторных работ

### LAB1: Основы Prolog и работа со списками

**Задача 1 (Вариант 6):** Удаление N последних элементов списка  
**Задача 2 (Вариант 11):** Вычисление позиции максимального элемента

**Ключевые файлы:**
- `lab1/task1.pl` — операции над списками
- `lab1/task2.pl` — анализ базы данных студентов

**Реализованные предикаты:**

| Предикат | Назначение |
|----------|-----------|
| `remove_last_n_std/3` | Удаление N элементов (стандартный способ) |
| `remove_last_n_rec/3` | Удаление N элементов (рекурсивный) |
| `max_pos_std/2` | Позиция максимума (стандартный) |
| `max_pos_rec/2` | Позиция максимума (рекурсивный) |
| `length_rec/2` | Длина списка |
| `member_rec/2` | Проверка принадлежности |
| `append_rec/3` | Конкатенация списков |
| `remove_rec/3` | Удаление элемента |
| `permute_rec/2` | Генерация перестановок |
| `sublist_rec/2` | Проверка подсписка |

**Примеры запросов:**
```prolog
?- remove_last_n_rec([1,2,3,4,5], 2, R).
R = [1, 2, 3].

?- max_pos_rec([3,7,2,9,1], Pos).
Pos = 4.

?- permute_rec([1,2,3], P).
P = [1, 2, 3] ;
P = [1, 3, 2] ;
P = [2, 1, 3] ;
...
```

**База данных студентов:**

Анализ успеваемости студентов с функциями:
1. **Средний балл по предметам** — `avg_grade_per_subject/0`
2. **Несдавшие студенты по группам** — `failed_per_group/0`
3. **Несдавшие студенты по предметам** — `failed_per_subject/0`

```prolog
?- avg_grade_per_subject.
Предмет Английский язык: средний балл = 3.90
Предмет Информатика: средний балл = 3.95
Предмет Логическое программирование: средний балл = 3.95
...

?- failed_per_group.
Группа 101: не сдало 2 студентов(-а)
Группа 102: не сдало 3 студентов(-а)
...
```


### LAB2: Логические задачи

**Задача (Вариант 6):** Чук и Гек

Классическая логическая головоломка. Два персонажа врут в определенные дни:
- **Чук** врет: понедельник, вторник, среда
- **Гек** врет: вторник, четверг, суббота

**Условия:**
1. Первый говорит: "Меня зовут Чук"
2. Первый говорит: "Вчера было воскресенье"
3. Второй говорит: "Завтра будет пятница"
4. Второй говорит: "Я всегда говорю правду по средам"

**Решение:**
```prolog
?- solve(First, Second, Day).
First = gek,
Second = chuk,
Day = monday.
```

**Архитектура решения:**
- Предикаты `lies/2` и `tells_truth/2` для моделирования поведения
- Предикаты `says_*/2` для проверки утверждений
- Перебор всех комбинаций с проверкой ограничений

**Дополнительно:**
- `lab2/лк1.md` — конспект с задачами (Зебра, Слесарь, Домино)
- `lab2/лк2.md` — примеры с простыми числами, решето Эратосфена, задача про рыб


### LAB3: Поиск в пространстве состояний

**Задача (Вариант 6):** Перемещение черных и белых шаров

**Начальное состояние:** `[ч,ч,ч,ч,п,б,б,б]`  
**Целевое состояние:** `[б,б,б,п,ч,ч,ч,ч]`

**Правила:**
- Черные шары двигаются только **вправо**
- Белые шары двигаются только **влево**
- Можно переместиться в соседнюю пустую лунку
- Можно перепрыгнуть через один шар в пустую лунку

**Реализованные алгоритмы:**

| Алгоритм | Предикат | Характеристика |
|----------|----------|----------------|
| DFS | `solve_dfs/1` | Поиск в глубину (быстрый, не оптимальный) |
| BFS | `solve_bfs/1` | Поиск в ширину (оптимальный путь) |
| IDDFS | `solve_iddfs/1` | Итеративное углубление (память + оптимальность) |

**Результаты:**
```prolog
?- solve_bfs(Solution).
Решение найдено за 0.012 сек
Длина пути: 24 ходов

?- solve_iddfs(Solution).
Решение найдено за 0.089 сек
Длина пути: 24 ходов
```

**Сравнение алгоритмов:**
- **DFS:** Быстро находит любое решение, но не гарантирует кратчайший путь
- **BFS:** Всегда находит кратчайший путь, но требует больше памяти
- **IDDFS:** Комбинирует преимущества DFS и BFS — находит кратчайший путь с минимальной памятью


### LAB4: Синтаксический анализ

**Задача (Вариант 6):** Синтаксический анализатор логических выражений

**Поддерживаемые операции:**

| Операция | Символ | Приоритет |
|----------|--------|-----------|
| Отрицание | `~` | 1 (высший) |
| Конъюнкция | `&` | 2 |
| Дизъюнкция | `V` | 3 |
| Импликация | `=>` | 4 (низший) |

**Архитектура:**
```
Выражение
    ↓
[DCG-грамматика] → AST (абстрактное дерево)
    ↓
[evaluate/2] → Результат (true/false)
```

**Факты истинности:**
```prolog
true(river_volga).
true(pupil_vasia).
true(sun_hot).
...
```

**Примеры запросов:**
```prolog
?- calculate([river_volga, '&', pupil_vasia], X).
X = true.

?- calculate(['~', false, 'V', river_volga], X).
X = true.

?- calculate([pupil_vasia, '=>', sun_hot], X).
X = true.

?- calculate(['(', false, 'V', river_volga, ')', '&', true], X).
X = true.

?- calculate([unknown_atom, '&', river_volga], X).
X = false.  % unknown_atom не определён как истинный
```

**Особенности реализации:**
- DCG (Definite Clause Grammar) для парсинга
- Построение AST (Abstract Syntax Tree)
- Рекурсивное вычисление с учетом приоритета операций
- Поддержка констант `true` и `false`
- Обработка скобок для изменения порядка вычислений

```bash

cd lab1
swipl -s task1.pl

# В интерактивном режиме
?- remove_last_n_rec([1,2,3,4,5], 2, R).
R = [1, 2, 3].

?- halt.  # Выход
```

### Полезные команды SWI-Prolog

```prolog
% Загрузка файла
?- [файл].
?- consult('путь/к/файлу.pl').

% Перезагрузка всех измененных файлов
?- make.

% Трассировка выполнения (отладка)
?- trace.
?- your_predicate(Args).
?- notrace.  % Отключить трассировку

% Список всех предикатов файла
?- listing.
?- listing(имя_предиката).

% Справка
?- help(append).
?- apropos(list).  % Поиск по ключевому слову

% Выход
?- halt.
```
