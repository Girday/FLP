Познакомиться на практике с методами анализа естественно-языковых текстов в системах логического программирования (Пролог), реализовать в соответствии с вариантом задания несложный фрагмент естественно-языкового интерфейса к модельной задаче и протестировать его на ряде примеров.

## Вариант 6: Синтаксический анализатор логических выражений

### **Задание**
Реализовать синтаксический анализатор логического выражения и вычислить его значение.  
В выражении допустимы операции:

- **Отрицания** (`~`)
- **Дизъюнкции** (`V`)
- **Конъюнкции** (`&`)
- **Следования** (`=>`)

Истинными считаются только те атомарные высказывания, которые заданы фактами вида:

```prolog
true(river_volga).
true(pupil_vasia).
```

### **Пример запроса и результата**
```prolog
?- calculate([false, 'V', river_volga, ')', '&', true], X).
X = true.
```

### **Требования к программе**
1. Программа должна быть написана на языке **Пролог**.
2. Предикат `calculate/2` принимает на вход список, представляющий логическое выражение в инфиксной форме, и возвращает его логическое значение (`true` или `false`).
3. Необходимо учитывать:
   - Приоритет операций (отрицание → конъюнкция → дизъюнкция → следование)
   - Скобки для изменения порядка вычислений
   - Атомарные высказывания, истинность которых определяется фактами `true/1`
4. Если атомарное высказывание не задано фактом `true/1`, оно считается ложным.

### **Что должно быть реализовано**
- Грамматика логических выражений
- Предикат синтаксического разбора
- Предикат вычисления значения выражения с учётом фактов истинности
- Обработка констант `true` и `false`
